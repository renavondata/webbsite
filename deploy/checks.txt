# Healthchecks-style checks this deployment expects to exist on the operator's
# monitoring instance (a self-hosted Healthchecks-compatible service; its
# hostname is operator infrastructure, not part of this public repo). Names
# and sizing only; the ping URLs are capabilities held in /etc/webbsite/*
# (see required-env.txt). All tagged `dataguru webbsite`, all on the shared
# email channel, each bootstrap-pinged once before its timer is armed (or the
# first run is a spurious DOWN). The timer cadence and the check's
# timeout/grace are ONE decision: change one, change both.
#
# Pipe-delimited so scripts/assert_box.py can read it: a check whose status is
# `live` must exist on the monitoring instance, be unpaused, and have a channel.
#
# name | kind | timeout or schedule | grace | status | pinged by
webbsite-refresh           | cron   | daily           | 6h    | live | webbsite-refresh.service via HC_URL (+ -failed.service on failure)
webbsite.renavon.com-probe | simple | 300s            | 600s  | live | the operator's external probe runner (site.toml probe_external); no on-box probe
webbsite-deploy            | simple | 600s            | 900s  | live | site-deploy@webbsite.service heartbeat via HEALTHCHECKS_DEPLOY_URL (env)
webbsite-invariants        | cron   | daily 04:30 UTC | 6h    | live | webbsite-invariants.timer via HC_INVARIANTS_URL; armed 2026-09-17
webbsite-cf-drift          | simple | 86400s          | 6h    | live | cf-drift@webbsite.timer (daily dry run) via HEALTHCHECKS_CF_DRIFT_URL (cf-env)
webbsite-backup            | simple | 86400s          | 4h    | live | site-backup@webbsite.timer (daily) via HEALTHCHECKS_BACKUP_URL (backup-env); grace > backup_timeout (2h)
webbsite-checks-armed      | simple | 900s            | 1800s | live | site-checks-armed@webbsite.timer via HEALTHCHECKS_ARMED_URL (ops-env); asserts the rows above
#
# Composition (borrowed from the fleet): the instance canary asks "can the
# monitoring instance still ALERT?"; its checks-armed sweep asks "is each
# dataguru check ARMED (not paused)?"; these dead-men ask "did the job RUN?".
# Each is blind to the others.
# A stale upstream feed pages twice by design: /health?deep=1 (probe) and the
# loader's own /fail (refresh) see the same fact from two vantages.
